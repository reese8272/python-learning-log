## Path B — VidMob direct
- Check https://vidmob.com/careers for the same or an adjacent AI/ML–MCP role.
- If present, apply directly with the same resume + a short cover note reusing the MCP + autoclip.studio hook above.
- Rationale: applying direct removes the staffing markup, which can mean a higher effective rate and a shorter feedback loop. It also signals genuine interest in *their* product, not just a contract.
- Not exclusive with Path A — but if you get traction directly, mention it early so a recruiter doesn't submit you to the same client (double-submission can get a candidate disqualified).

---

## Staffing-firm dynamics (know before you talk)
- Activesoft **places** you at the end client and takes a margin. Your relationship is with them first.
- **Pin down early:** target bill/pay rate, W2 vs C2C vs 1099, contract vs contract-to-hire vs direct, and confirm **fully remote**.
- Ask **which end client** (politely) — they may or may not name VidMob. Don't assume it aloud until confirmed.
- Get any submission **in writing** with the rate you agreed to, so you're not surprised at offer stage.
- Avoid being submitted to the same client by two firms — clarify exclusivity per submission.

## Follow-up cadence
- **Day 0:** Send LinkedIn note (both recruiters) + apply on Dice + check/apply VidMob direct.
- **Day 2–3:** If no reply, follow up once with the longer message + resume.
- **Day 5–7:** Final nudge; if still silent, the Dice application and VidMob-direct path carry it.
- Keep it to **2 follow-ups max** per recruiter — persistent, not pushy.
