# Focus & Time Block Protocol

*The "how to manage my time and focus" reference. Built 2026-07-23 from live research mapped against this system's own logs. Pull this up when a time block needs designing, a block keeps failing, or focus feels broken and you want the fix that's backed by evidence — not a new system.*

**The one-line version: your focus problems are cue-design problems, never willpower problems. Fix the environment, not yourself.**

---

## The Block Protocol — run this for any deep work block

Use this checklist to set up the peak block (9:45) or any focused sitting. Steps 1–3 are the setup; 4–6 are the in-block rules.

1. **Phone leaves the room.** Not silenced, not face-down — *in another room, on the charger*. Same cue as the 10:25 brick, running a second shift. (Why: mere presence drains working memory even untouched — see Science #1.)
2. **Cardio before peak, when possible.** 20–30 min zone-2 pre-loads dopamine/BDNF for hours. Morning gym day = chemistry already paid for. No gym = note it as a variable, don't cancel the block.
3. **One thing, pre-named.** The block does one rep — a `/sharpen` defense, one `/learn` concept, one application. Named *before* sitting down, ideally the night before or in the stopped-at line. Never "work on stuff."
4. **Parking-lot pad open.** One card or file beside the keyboard. Every intrusive thought — a plan, a course to check, a system tweak, tonight's big idea — gets **one written line**, then back to the task. Chase nothing mid-block. (This is the 10pm rule generalized: plans that appear mid-block go to the pad, never into same-block action.)
5. **Optional doorway: 5 min eyes-closed breathing** before the first hard thing (the therapist homework, grafted to the peak-window cue). Upside, never owed.
6. **Close with a stopped-at line.** "Stopped at: [X]. Next step: [Y]." One sentence kills tomorrow's re-entry cost. A block isn't finished until this is written.

**Worst-day minimum:** phone out of the room + one named thing + 10 minutes. That's a real block. Everything else is upside.

## Time-block placement rules

- **Peak window (90–180 min post-medication) takes only the hardest, most novel work** — `/sharpen`, `/learn`, cert material, papers, capstone. Email, Slack, admin, tinkering, and passive review are *banned* from this window, forever. The window is the asset.
- **Admin rides existing blocks** (the 12:00 pipeline block pattern): batch shallow work into one named non-peak sitting and don't leave the seat until the batch is done. Follow-ups are the floor of the sitting; the highest-ROI item goes in the same sitting.
- **Mechanical work never gets peak minutes.** If it's rote (running a script to green, easy-apply batches, uploads), it's an evening or gap-time item.
- **New plans that appear after 10pm go to the next check-in**, never into same-night action. The late-night surge is real energy — route it through an audit, not a launch.
- **One build at a time.** When focus breaks system-wide, the answer is one brick, not a redesigned stack. Over-launch is the documented collapse signature (4/09, 5/01, 6/16).

## When a block keeps failing — diagnostic order

Work down this list; stop at the first yes.

1. **Was the phone in the room?** → That's the leak. Fix the cue, not the person.
2. **Was the one thing pre-named?** → "Deciding what to do" burned the activation energy. Name it the night before.
3. **Did the block start with something shallow** (email, a quick check)? → Attention residue contaminated the block. Hard thing first, always.
4. **No cardio + no meds that day?** → Chemistry variable. Log it, shrink the block to the 10-min minimum, don't read it as failure.
5. **Block still won't start?** → Body double it: virtual co-working, or work where someone is present. Externalized presence cuts activation energy. (On-deck tool, not a habit to build.)
6. **Failing for a week+?** → It's a cue-design failure. Re-graft the block to a different anchor, same as any habit. Never conclude "no discipline."

## The science (why each rule exists)

1. **Phone out of the room — the "Brain Drain" effect.** The mere presence of your own smartphone — silent, face-down — measurably reduces working memory capacity and fluid intelligence, because *inhibiting* the automatic pull toward it consumes the attentional resources you're trying to spend. Another room > pocket > desk. The effect is largest for high-dependence users, and working memory is already the constrained resource in ADHD. ([Ward et al., JACR 2017](https://www.journals.uchicago.edu/doi/full/10.1086/691462); [meta-analysis](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10525686/) — debated at population level, but the right bet for a high-dependence ADHD brain.)
2. **Implementation intentions (if-then cues).** Pre-deciding when/where/how ("water on → line one," "sit down → phone to charger") offloads action initiation from executive function to the environment — the exact function that's unreliable in ADHD. If-then plans improve inhibition and follow-through in ADHD samples. ([APSARD](https://apsard.org/managing-adhd-what-is-your-implementation-plan/); [Gawrilow/Gollwitzer ADHD studies](https://www.researchgate.net/publication/225234656_If-Then_Plans_Benefit_Delay_of_Gratification_Performance_in_Children_With_and_Without_ADHD).) "Cue failure, not willpower" is the scientifically correct frame.
3. **Acute exercise → inhibitory control.** Meta-analysis in adults with ADHD: moderate improvement in inhibitory control (g = 0.55) — the faculty that resists distraction — plus small gains in core symptoms, via dopamine/norepinephrine elevation (partially stimulant-like) and BDNF. ([PS&E 2026 meta-analysis](https://www.sciencedirect.com/science/article/abs/pii/S1469029226000282); [acute aerobic RCTs](https://pmc.ncbi.nlm.nih.gov/articles/PMC6443849/).) Cardio-before-peak is validated, and morning gym makes it structural.
4. **CBT-for-ADHD components.** The best-evidenced non-medication treatment. The components that work hardest: organizational strategies (= the Card/the Floor), problem-solving (= the diagnostic list above), and third-wave mindfulness (= the 5-min doorway). The parking-lot pad is the standard CBT "distractibility delay" technique. ([43-trial meta-analysis, 2025](https://www.news-medical.net/news/20250205/Can-cognitive-behavioral-therapy-components-be-tailored-to-optimize-ADHD-treatment.aspx); [RCT for inattentive presentation](https://www.frontiersin.org/journals/psychiatry/articles/10.3389/fpsyt.2025.1564506/full).)
5. **Attention residue.** After any task switch, part of attention stays glued to the previous task — amplified in ADHD. Prevention: hard thing first, one thing per block. Recovery: the stopped-at line, which is why re-entry from a written line beats re-reading everything.
6. **Body doubling.** Another person's presence externalizes motivation and reduces the activation energy to start — modest but consistent evidence in ADHD. ([overview](https://amfmtreatment.com/blog/how-to-stop-getting-distracted-with-adhd-5-strategies-to-try/).) Held as a rescue tool, not a scheduled habit.

## What this protocol deliberately does NOT ask

- No new apps, timers, or systems. The system exists; this doc is how to run a block inside it.
- No stacking. Two cue-extensions (phone-out at block start, the pad) ride cues that already work. Everything else here was already in the system — the science just explains *why* it works, which makes it easier to trust on a bad day.
- No perfect days. A block that hits the worst-day minimum counts. Gaps are data, never debt.
