# SYSTEM.md — The Blueprint

*Built 2026-07-23 by rebuilding the entire system from scratch, on paper, from first principles — identity → chemistry → floor → time → engines → feedback. The result converges on what four months of logs already selected for, which is the proof it's right: this architecture wasn't theorized, it survived. This document is the constitution — the one place the whole machine is written down. Everything else (the Card, the tracker, CLAUDE.md, the protocols) is an instrument of this.*

**What "statistically unbeatable" honestly means:** no system produces perfect days, and any system promising that is the over-launch trap wearing a suit. This system is unbeatable in the expected-value sense: **the downside of any failure is capped at one day, and re-entry costs three minutes.** Upside is uncapped; variance is survivable; failure cannot compound. You don't win by never falling — you win because falling costs almost nothing and the way back is always the same door. That is a bet you cannot lose over a year.

## Layer 2 — The Floor (the minimum viable day)

The counter to the documented #1 failure mode: all-or-nothing collapse (4/09, 5/01, 6/16). The floor caps the downside.

- **A day counts on 2 items:** 🧱 the 10:25 brick · 📨 one job-pipeline touch (until hired). Everything else in the system is upside, never owed.
- **Bad-day rule:** ONE non-negotiable (presence with the kids, or the brick) still makes the day count.
- **Interface:** `/checkin` — 3 minutes, phone-friendly, updates the Card, logs, pushes.
- **Re-entry rule:** after any gap, the way back is `/checkin`. Gaps are data, never debt. No archaeology.
- **The Card** (`agenda.md`) is the front door and must always reflect NOW.

## Layer 4 — The learning engine (what you wanna know)

Governed by `career/helpful_notes_and_guides/Learning Science Protocol.md` — the evidence base for every rule below, plus the diagnostic for when something won't stick.

Three-stage, in-catalog, phone-friendly, always live-researched: **`/learn`** (acquire from zero) → **`/sharpen`** (defend cold at the depth bar) → **`/drill`** (retain, spaced + interleaved). **One track is ACTIVE at a time** (declared on the Card); the rest are dormant, because over-launch is how this has died before. Logs mastery to `CAREER_LOG.md`. Courses are gap-fillers only.

- **Depth bars** `[A]` build it / `[B]` explain it / `[C]` name it — the bar is the rationing decision and binds both ways.
- **The Ladder** — fill-in-the-blank → short answer → spot-the-bug → completion problem → the project. Scaffolding is removed one rung at a time and never re-added; the fade *is* the teaching.
- **Build before you bank** — a concept isn't owned until code using it exists somewhere real; five minutes counts.
- **Delayed `[x]`** — a teaching session can only mark `[~]`. Banking requires the worksheet green or a cold re-ask in a *later* session. Confidence measured right after learning is the least reliable signal there is.
- **Cadence** (not floor): one peak rep + one non-peak drill per day.

## Layer 6 — Feedback loops (the filter that keeps it honest)

`/checkin` (daily, 3 min) → `/reflect` (when there's something to process) → `/weekly-review` (game film) → `/monthly-review` (highest zoom). Content survives the **3-iteration filter** (daily → weekly → monthly) or it wasn't load-bearing. Design changes land in `DECISIONS.md`; habit truth lives in `habits/tracker.md`; coaching memory in Coach Notes. **A stale Card is a system bug** — any state-changing session leaves it accurate.

## The Failure-Mode Playbook — every known collapse, pre-answered

*These are the five ways this system has actually died, each with its engineered counter. When something feels broken, find the row — the answer is already written.*

| Failure mode | Signature | Counter |
|---|---|---|
| **All-or-nothing collapse** | External hit → whole stack down → guilt blocks re-entry for weeks (4/09, 5/01, 6/16) | The Floor caps the day's cost; `/checkin` re-enters for 3 min; gaps are data, never debt |
| **Over-launch** | Surge of motivation → rebuild everything at once → nothing sticks (signature of every collapse) | One build at a time; new bricks only after the current one is Active; this document changes *zero* behaviors by itself |
| **Late-night surge** | Big plan appears after 10pm, demands action tonight | Route to a pre-action audit / next check-in (proved twice: certs 07-20, contractor 07-23) |
| **Cue eviction** | A habit "falls" because life moved its trigger (midday gym killed by work) | Diagnose the cue, not the discipline; re-graft to a new anchor as a *new build* |
| **Adjacent-habit swap** | Build feels heavy → a smaller nearby habit quietly replaces it (stretching nearly replacing gym, 07-20) | Invoke the real build's worst-day minimum instead |
| **Judgment-exposure spiral** | Rejections/being-watched read as verdicts → "I don't know enough" | Rejections are signal already being acted on; curiosity over ranking; the fear vanishes where no one's watching — proof it isn't skill |
