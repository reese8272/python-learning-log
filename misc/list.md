# The Misc List

The catch-all backlog — stuff worth getting into that has no concrete home yet. Block a "misc" time slot, open this, pick one, go. No order, no obligation. Add freely, prune never-gonna-happens without ceremony.

**How it works:**
- Anything goes on the list the moment it sparks. No vetting at capture time.
- When a misc block is on the calendar, pick whatever pulls hardest that day.
- If something graduates into a real thing (a reading, a project, a career move), route it to its proper folder and check it off here with a pointer.
